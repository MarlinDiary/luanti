# SDK 0.11.5 收尾与验收

日期：2026-09-09。基线 SDK 0.11.4；原生客户端保持 0.8.0，Python 仍为 3.9+、零运行时依赖。

## 修复了什么

1. **示例不再把正常抢占当失败。** `survival_collect.py` 区分明确的 `survival_interrupted + intervention` 和真正失败；后继反应失败仍停止。暂停后不继续采集，等待反应结束后重新观察背包并计算剩余目标。
2. **交接期间不误报空闲。** 旧反应被更紧急的反应抢占后，`Survival` 保持 successor pending。下一次观察执行后继反应或确认无需反应后才清除，避免普通任务插入两次反应之间。
3. **成功进食后恢复原持物。** 自动进食和 `eat_best_food()` 正常成功后，用精确物品身份寻找原物品，包括快捷栏满时被移入背包的工具。紧急取消、人工接管及其他控制变更优先，不在 finally 里强制切回。原物品丢失或已换持物时不覆盖新状态。

不改显式 `game.eat(item)` 的持物语义，不自动重放采集，不加入课程发展策略。完整 API 语义见 [生存 API](survival.md)。
